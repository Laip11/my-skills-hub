# Research Visual Report

将结构化调研 Markdown 构建成专业的交互式单文件 HTML。报告支持方法分类、论文搜索、时间排序、折叠卡片、深色模式和打印布局，并对内容覆盖、日期顺序和图片路径执行构建检查。

论文卡片固定展示三个信息块：`核心问题 / 背景`、`具体方法`、`实验设置和结果`。每篇至多展示一张主图，置于标题和来源信息下方。

## 调用

- Codex：`$research-visual-report 把 report.md 构建成网页`
- Claude Code / Cursor：`/research-visual-report 把 report.md 构建成网页`

完整工作流见 [`SKILL.md`](SKILL.md)，配置说明见 [`references/config.md`](references/config.md)。
