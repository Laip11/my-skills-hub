# Paper Evidence Research

基于论文正文、表格、附录和原始图表开展可追溯的文献调研。输出包括结构化 `report.md`、证据账本、待核实事项和经过授权检查的论文主图。

## 适合的任务

- 系统性调研一个研究问题或方法谱系
- 比较多篇论文的机制、实验、成本与局限
- 从 arXiv HTML 或 PDF 提取论文主图
- 为 `research-visual-report` 准备专业的图文调研材料
